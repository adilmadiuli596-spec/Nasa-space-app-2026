# N4B.3 — UX панели научного анализа

Дата: 2026-11-15. Бюджет: 0 KZT. Научные формулы, NASA POWER API, GIBS API и кэш не менялись.

## Изменения

- «Обзор» показывает тренд с направлением, понятный вывод о статистической значимости, краткое объяснение, p-value и 95% доверительный интервал. Большой график из обзора убран.
- «Графики» показывает годовые значения NASA POWER и OLS на основной доступной высоте панели; добавлен компактный tooltip с годом и обеими сериями. Легенда расположена над графиком, период и число лет — под ним.
- «Методика» начинает с трёх понятных шагов. Технические параметры OLS/HAC/Newey–West, lag 3, Student t, интервал и ограничения доступны в свёрнутом блоке.
- Дата GIBS подписана как «Время карты». Выбор периода анализа подписан отдельно как «Период исследования».
- Карточка точки показывает, что значение является среднегодовым, указывает год и период исследования.
- T2M/QV2M по-прежнему используют готовую пару результатов; при переключении показателя новый запрос не нужен.

## Проверки

- `npm run boundaries` — пройдено как часть production build.
- `npm run typecheck` — пройдено.
- `npm run build` — пройдено.
- Локальный browser smoke на production build: 1 запрос анализа, ошибок JavaScript нет; переключение на QV2M отражено на графике. Ширина документа на mobile 390 px — 390 px.
- Публичный `/api/health` ответил 200 и сообщил режим NASA POWER.
- Один реальный парный NASA POWER запрос по Павлодару: HTTP 200, 35 годовых значений за 1991–2025. Время ответа 573 мс; наклон T2M `0.09126906922661153 °C/десятилетие`; 95% ДИ `[-0.19129611488872628, 0.37383425334194936]`.
- Скриншоты собраны на локальном production build с реальным ответом публичного NASA POWER API. 2D карта отображалась; отдельные проверки взаимодействий 3D и независимого выбора даты GIBS не выполнялись.
- Публичная страница Vercel отвечает 200, но набор production JS bundle отличается от локальной сборки после push. Новый deployment и внешний анализ новой версии пока не подтверждены.
