# Earth Detective
Дата актуализации: 2026-11-14. N1–N3 приняты; актуальная работа N4A по новому заданию.

Единое приложение Next.js App Router + TypeScript, один локальный Git-репозиторий, один планируемый деплой Vercel Hobby. Бюджет строго 0 KZT. React/Vite и Python/FastAPI сохранены только как исторический исходник и научный эталон в reference/.

MVP: выбор географической точки/ячейки и T2M либо QV2M, реальные месячные ряды MERRA-2 за 1991–2025, взвешенные по дням годовые значения, OLS и HAC/Newey–West, графики и понятное объяснение неопределённости. Произвольные полигоны/региональное усреднение пока не реализованы. Выбор региона в текущем UI означает выбор точки и ближайшей ячейки, а не среднее по области.

N1/N2 приняты, N3 реализует локально авторизованный NASA adapter и работающий analysis API. По умолчанию public dynamic blocked; отдельный demo только для двух сохранённых реальных ячеек. Успешные fresh проверки трёх ячеек и ограничения описаны в MIGRATION_N3.md. Старый проект не изменяется. Python не запускается как второй сервис нового приложения.

Не включать Groq, ML, пользовательскую авторизацию, платную БД, дополнительные сервисы. 3D полностью вне нашей ответственности; другой участник реализует его самостоятельно. Не создавать и не интегрировать его код; 3D не блокирует готовность 2D. Деплоя и push нет.

N4 завершил UI, настоящие NASA browser-проверки и подготовку package/runtime; подробности MIGRATION_N4.md. N5 (публикация) не начат, требуется отдельное разрешение.

Актуальная итерация — N4A по новому референсу, отчёт MIGRATION_N4A.md. N4B (GIBS temperature) и N4C (global trends) только запланированы, 3D за другим участником. Поиск теперь реальный Photon city/coordinates; глобальные научные слои не подключены.
