# Earth Detective — постоянные инструкции для ИИ-агентов

## Границы работы

- Работать только в `D:\Projects\NASA`. Если этот путь недоступен для записи, запросить стандартное разрешение и сообщить фактический результат. Не обходить sandbox, не менять ACL и настройки Windows.
- Один проект и один репозиторий. Код интерфейса размещать в `frontend/`, серверный код — в `backend/`. Не создавать копии проекта, дополнительные репозитории и лишние папки. Сейчас эти каталоги ещё не реализованы; их наличие в документации является планом.
- Новую документацию проекта размещать только в `docs/`. Этот корневой `AGENTS.md` — обязательное исключение. Исторические научные отчёты в `.data-check` не перемещать ради этого правила.
- Не менять утверждённый дизайн: глобальная карта, плавающий header, инструменты и масштабирование слева, выдвижная правая панель анализа, акцент `#102744`. Подробности — `docs/DESIGN.md`.

## Обязательный бюджет: 0 KZT

- Общий бюджет проекта всегда **0 KZT**. Приоритет — локальный запуск на имеющемся оборудовании бесплатными инструментами и, при соблюдении лицензии, Docker Compose.
- Без отдельного явного согласования запрещены платные API, библиотеки, сервисы, хостинг, карты, геокодирование, облачные вычисления, хранение и ИИ; подключение биллинга или карты; обязательные платные тарифы; автоматический переход с бесплатного тарифа на платный.
- До подключения любой зависимости проверить первоисточник: лицензию, тариф, лимиты, условия публичной эксплуатации, атрибуцию, необходимость карты и поведение при превышении лимитов. Не называть сервис бесплатным без подтверждения. Записывать источник и дату проверки в `docs/COST_POLICY.md`.
- Бесплатная библиотека карты не означает бесплатность тайлов, геокодера или хостинга. Docker Desktop бесплатен только для разрешённых его лицензией сценариев.
- Если функция требует расходов, сообщить об этом и предложить вариант за 0 KZT. Не активировать оплату самостоятельно. Для изменения бюджета требуется отдельное явное решение пользователя и обновление политики.

## Научные данные и секреты

- Использовать реальные данные NASA MERRA-2 с идентификаторами продукта, версии, времени, единиц и фактической ячейки. Не придумывать измерения, статистику, результаты тестов и успешные загрузки.
- `.data-check` и исходный `MERRA2_100.tavgM_2d_slv_Nx.199101.nc4` — защищённый научный эталон. Не изменять и не удалять их без обоснованной необходимости и отдельного разрешения пользователя. Разрешено чтение без записи и проверка контрольных сумм. Не запускать скрипты, перезаписывающие результаты, без разрешения.
- Не представлять ряд Павлодара как данные другой ячейки. Применять его только при совпадении фактической ячейки и запрошенного периода; источник и использование эталона должны быть явно указаны.
- Методика и подтверждённые числа — в `docs/SCIENCE.md`; первоисточник результатов — `.data-check/analysis_results.json` и независимые проверки. Не подменять научные выводы ожидаемым направлением тренда.
- Earthdata username, пароль, токены, cookies и заголовки авторизации не должны попадать в исходники, ответы API, документацию, логи, Git или образы Docker. Никогда не просить пароль/токен в чате. Использовать безопасный локальный ввод или окружение процесса, без сохранения в коде.
- Исключать секреты и рабочий кэш из Git и Docker build context. Не считать `.gitignore` защитой уже отслеживаемых файлов. Не добавлять базу данных без необходимости и согласованного обоснования.

## Порядок этапов

- Работать строго по этапам из `docs/PROGRESS.md`. Выполнение работы и утверждение пользователем — разные статусы.
- После каждого этапа предоставить полный отчёт: изменённые файлы, фактическое поведение, проведённые тесты с результатами, ошибки, ограничения, расходы и оставшиеся вопросы. Обновить документацию в `docs/`.
- После отчёта остановиться и дождаться проверки и явного утверждения пользователя. Не переходить к следующему этапу самостоятельно. Ранее общее разрешение разработки не отменяет более позднюю остановку на конкретном подэтапе.
- Не выполнять `git push`, деплой, публикацию или подключение платной услуги без отдельного разрешения. Не создавать публичный доступ автоматически.
- Текущее поручение: только `AGENTS.md` и документация. Backend, frontend, Docker-конфигурацию и 3D-глобус в рамках этого поручения не реализовывать.
