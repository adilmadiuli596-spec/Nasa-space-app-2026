## Границы источника и периода

`DataSource` отделён от статистического ядра. Сейчас подключён только `LocalReferenceSource`: реальные проверенные данные ячейки **52.5° N, 76.875° E** за 1991–2025. Читаются месячные исходные значения и отдельные metadata/manifest. SHA-256 трёх входных артефактов закреплены в источнике; при несоответствии ответ 503, а не «исправление» эталона. Показатели тренда не зашиты в приложение — они вычисляются из ряда при каждом запросе.

Координаты выбирают ближайший центр сетки 0.5° × 0.625°. Долгота замыкается у ±180°, при равном расстоянии выбирается меньший индекс массива. Запрошенная точка и фактическая ячейка всегда возвращаются отдельно. Другие координаты внутри той же ячейки получают тот же честно подписанный ряд; другая ячейка получает 404 `data_not_available`. Даже внедрённый другой provider проверяется на соответствие ячейки запросу.

Период задаётся целыми `start_year`, `end_year` внутри 1991–2025. Только полные календарные годы, минимум **5 последовательных лет**: n > maxlags + 1 при лаге 3 и положительные остаточные df. Это технический минимум, не обещание точности статистики; для n < 20 добавляется предупреждение. Частичные годы, пропуски, дубли, неправильный порядок, нечисловые и fill-значения отвергаются. Базовые предупреждения о реанализе, приближённости HAC и отсутствии станционной проверки включены в каждый результат.

Для постоянного ряда возвращается slope=0, а p-value, ДИ и значимость — null с объяснением. Для точно линейного ряда с нулевой остаточной вариацией сохраняется вычисленный наклон, но вывод о значимости также не выдумывается. Тест вырожденности использует порог 64 × машинный epsilon × max(1, max|годового значения|), чтобы не трактовать округление как реальную остаточную вариацию.

## API и запуск

| Запрос | Поведение |
|---|---|
| `GET /api/health` | 200 при доступном эталоне; 503 при отсутствии/несовпадении SHA. `nasa_network=not_checked` |
| `GET /api/variables` | Переменные, исходные/отображаемые единицы, доступная ячейка, период и минимум лет |
| `POST /api/analysis` | Научный результат, месячные/годовые ряды, ячейка, происхождение и предупреждения |
| `GET /openapi.json` | Pydantic-схема результата и реальной структуры ошибок |

Ошибки `/api/analysis`: 422 `invalid_request` для неверного запроса; 404 `data_not_available`; 503 `reference_unavailable`/`reference_integrity_error`/`coordinate_mismatch`; 500 `internal_error` для непредвиденного сбоя. Научные ошибки имеют отдельные коды. Невалидное тело не отражается обратно в ошибке. Непредвиденные исключения логируются только по имени класса; текст исключения/путь/тело запроса не выдаются. Swagger/ReDoc HTML отключены, чтобы не загружать CDN; схема остаётся локальной. Привязка запуска ниже только к loopback, не публичный деплой.

Существующее окружение уже установлено. Запуск из PowerShell:

```powershell
& "D:\Projects\NASA\backend\.venv\Scripts\python.exe" -B -m uvicorn earth_detective.main:app --app-dir "D:\Projects\NASA\backend" --host 127.0.0.1 --port 8000
```

По умолчанию эталон читается из корневой `.data-check`. Переменная окружения `EARTH_REFERENCE_DIR` может указывать другую локальную копию **того же закреплённого эталона**; она не разрешает подменить данные произвольным набором. Earthdata-пароль и токен не требуются. HTTP-клиенты применяются только в локальных тестах; в исходнике NASA-источника нет сетевого клиента или авторизации.

Для воспроизведения окружения с уже имеющимся uv (внутри проекта) и Python 3.13:

```powershell
Set-Location D:\Projects\NASA
.data-check\bootstrap\bin\uv.exe venv backend\.venv --python .data-check\venv\Scripts\python.exe --cache-dir backend\.cache\uv
.data-check\bootstrap\bin\uv.exe pip sync backend\requirements.lock --python backend\.venv\Scripts\python.exe --default-index https://pypi.org/simple --cache-dir backend\.cache\uv --link-mode copy
```

Команды не требуют изменения `.data-check`; используются только имеющиеся исполняемые инструменты. Для отдельного нового окружения также подходит стандартный `python -m venv` и установка lock-файла через pip; платные package services не нужны. Lock проверен в Windows/Python 3.13.18; Linux/Docker этим этапом не тестировались.

## Совпадение науки

| Показатель | Тренд за десятилетие | p-value | 95% ДИ |
|---|---:|---:|---|
| T2M, °C | 0.09179457757906843 | 0.5129513990556182 | [−0.1905748233841892; 0.3741639785423261] |
| QV2M, г/кг | 0.17981239344380076 | 0.0023834887902114427 | [0.06864540028217651; 0.290979386605425] |

Оба результата совпали с эталоном в полной показанной точности. В тестах rtol=1e-10, atol=1e-12: допускается только незначительная разница вычислений float64/линейной алгебры, а не отличие научного метода. Допуски существенно строже округлённых контрольных значений пользователя. Для 35 годовых средних проверено rtol=1e-12, atol=1e-12. Формулы не подгонялись под тесты. В API одного показателя p-value не подвергается скрытой поправке Holm.

## Обнаруженные проблемы и ограничения

1. Первоначально узкое разрешение backend/ не позволило создать несуществующий каталог: Windows Access denied. Стандартным запросом получено разрешение родительской папки; ACL и sandbox не обходились.
2. Starlette 1.10.0 предупреждает об устаревании httpx для TestClient. Вместо подавления предупреждения установлен совместимый httpx2; лицензия новых пакетов проверена. Во всём окружении зафиксированы 34 пакета.
3. В первоначальном подсчёте дней использовался отсутствующий `Index.sum`; исправлено на NumPy-сумму дней. Это техническая ошибка счётчика дней, не изменение годовых весов или формулы тренда. После исправления прошли тесты високосного года и эталона.
4. uv не смог использовать hardlink и скопировал wheel-файлы. Это повлияло только на установку/место на диске; для повторения указан `--link-mode copy`.
5. Пока нет динамического источника, NASA-аутентификации, сетевых таймаутов/повторов, дискового кэша произвольных ячеек или настоящих данных другой точки. Это умышленная граница 3B. Статистические ограничения остаются описанными в `SCIENCE.md`.
