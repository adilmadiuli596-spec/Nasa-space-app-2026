## Data and cartography

- [NASA POWER Monthly API](https://power.larc.nasa.gov/docs/services/api/temporal/monthly/) supplies numerical series; preserve response provenance and [meteorological source information](https://power.larc.nasa.gov/docs/methodology/data/sources_meteorology/).
- [NASA GMAO MERRA-2](https://gmao.gsfc.nasa.gov/gmao-products/merra-2/) is atmospheric reanalysis. Direct historical reference product: M2TMNXSLV V5.12.4, [DOI](https://doi.org/10.5067/AP1B0BA5PD2K); not a claim of identical POWER values.
- [NASA GIBS](https://nasa-gibs.github.io/gibs-api-docs/access-basics/) provides MERRA2_2m_Air_Temperature_Monthly visualisation tiles.
- [OpenFreeMap](https://openfreemap.org/), [OpenMapTiles](https://openmaptiles.org/) and [OpenStreetMap contributors](https://www.openstreetmap.org/copyright) provide basemap content; OSM geographic data remain under ODbL. Preserve on-map and screenshot credits.
- [Photon / Komoot](https://photon.komoot.io/) supports manual search with OSM attribution and service fair use.

NASA data, basemap content and provider marks are not relicensed by the root code licence. No provider endorsement is implied. Screenshots capture the real app and preserve provider attribution.
