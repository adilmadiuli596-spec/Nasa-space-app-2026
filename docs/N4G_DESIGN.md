# N4G — уточнение дизайна

Переключатель 2D/3D встроен единственным fieldset в левую панель инструментов под header; active #0B3D91, согласованные скругления. Desktop — вертикальное расположение, открытая мобильная панель — компактная строка.

3D: тёмно-синий фон на всю область за плавающим header, редкие мелкие декоративные CSS-звёзды, уменьшенный удобный масштаб в свободной области, native MapLibre atmosphere с голубым горизонтом. 2D остался прежней светлой картой. Светлая горизонтальная полоса под мобильным header устранена. На визуально проверенных экранах иных случайных горизонтальных полос не обнаружено.

Сохранены готовые компоненты друга. Для опциональной панорамы SpaceBackdrop принудительно используется его существующий облегчённый CSS-путь; он больше не создаёт второй WebGL-контекст. На mobile панорама выключена, звёзд 24 вместо 75. Кадры в покое не рисуются. Мягкое появление renderer 180 ms; prefers-reduced-motion отключает его и анимацию перелёта к точке. Плавное управление глобусом остаётся штатным MapLibre; новой 3D-системы и автоповорота нет.

Изменены App (компоновка), GlobeMapView (масштаб/atmosphere/motion), SpaceBackdrop (lightweight), n4g.css (оформление), metadata, browser script и документация. Backend, OLS/HAC, схемы научного результата, PairCache и зависимости сохранены; 45 защищённых файлов совпали по SHA-256. Новых научных переменных/слоёв/провайдеров/библиотек нет.

TypeScript PASS, boundaries и production build PASS. 11 локальных browser checks PASS: 2D/3D и выбор координат/sky rejection; реальный NASA POWER paired analysis; сохранение результатов и переменной; один WebGL с включённой панорамой; mobile/touch/reduced motion; освобождение ресурсов; fallback при WebGL/style error; корректная атрибуция. Один analysis POST за весь сценарий, 1803 ms, network_used=true, точка 53.85737, 53.43919. Неожиданных console/page ошибок 0; одна ожидаемая ERR_FAILED при искусственном abort стиля.

Скриншоты: N4G_DESIGN-2d.png, N4G_DESIGN-3d-desktop.png, N4G_DESIGN-3d-mobile.png. Проверены desktop 1440×900, mobile 390×844, отдельный touch-enabled/reduced-motion контекст. Физические устройства/FPS не измерялись.

Три референса, упомянутые в задании, к сообщению не приложились; оформление выполнено по подробному текстовому описанию, точное соответствие отсутствующим изображениям не заявляется.

Публикация: обычный commit/push origin main; live Vercel результат и SHA сообщаются после публикации. N4B не начат, GIBS-запросов и декоративных температурных текстур нет. Расходы 0 KZT.
