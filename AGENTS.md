# Earth Detective — правила агента
Актуальный стек: один Next.js App Router + TypeScript проект и один Git-репозиторий. Сфера нового проекта D:\Projects\Earth Detective. Исходный D:\Projects\NASA читать, не изменять.

src/app — страницы и тонкие HTTP; src/frontend — компоненты/карта/графики/styles; src/backend/nasa — NASA I/O, science — научная логика, cache — ограниченный кэш, services — orchestration; src/shared/types и schemas — общие контракты. docs — актуальные документы; docs/history — история; reference — сохранённые научные данные и исторические артефакты без Python-кода.

frontend импортирует только frontend/shared; backend — backend/shared; shared — только shared. Backend-модули должны импортировать server-only. Обязательна проверка npm run boundaries. Запрещены обходы через app/shared, переменные dynamic imports и копирование формул в UI/API. Научные алгоритмы реализуются один раз в backend/science; прежние spike entrypoints только делегируют этому ядру.

Проверенные численные JSON-эталоны сохраняются для TypeScript-тестов (rtol=1e-10, atol=1e-12), включая OLS/HAC lag 3 Bartlett correction Student t, units, days weights, missing, calendar и provenance. Не изменять scientific artifacts/ожидаемые числа ради теста. Не подменять Павлодар другой ячейкой. Координаты/результаты имеют единый shared контракт.

Бюджет строго 0 KZT. Не добавлять paid API, Groq/ML, пользователей, БД, дополнительные сервисы, billing/card/trials. Проверять лицензии и notices до новой зависимости. Не обещать бесплатный public Earthdata proxy без подтверждения правомерности. Секреты NASA только server environment; не NEXT_PUBLIC, Git, docs, API, логи, chat, screenshots. Никогда не копировать .env, .netrc, cookies, virtualenv, node_modules или runtime caches из исходника.

Тесты перед отчётом: boundaries, typecheck, npm test, production build, локальные HTTP health/variables/invalid+pending analysis, UI desktop/mobile и целостность SHA-256. NASA network/auth/HDF5 проверять отдельно; недоступное отмечать как not_verified. Исторические Python reports не называть свежим запуском.

Новый утверждённый визуальный референс N4A заменяет старый 4A.1; старый UI — источник логики. Разрешены новый header, tabs, palette #0B3D91/#071D49/#FC3D21, поиск городов/координат. Логотип только оригинальный public/brand/earth-detective-logo.png; при отсутствии не подменять. N1–N3 приняты. Разрешён только N4A: новый UI и анализ одной ячейки через N3 API, контракт карты/GIBS. N4B — отдельно глобальная температура GIBS, N4C — отдельно глобальные тренды; сейчас не реализовывать эти слои и 3D. Photon interactive geocoding разрешён новым заданием при fair-use, ограничении запросов/кэше/атрибуции и расходах 0 KZT. Научное ядро/формулы и сохранённые численные эталоны не менять. Earthdata public dynamic остаётся blocked до подтверждения допустимости; demo маркировать и не подменять произвольную точку сохранённой ячейкой. Бюджет 0 KZT.

3D-глобус и любые 3D-функции полностью вне нашей ответственности: другой участник делает их самостоятельно. Не создавать, не интегрировать и не изменять его код, не добавлять 3D-библиотеки; 3D не блокирует готовность 2D. Не перезаписывать файлы другого участника: проверять concurrent edits перед изменением существующей MapView. После MIGRATION_N4A.md и PROGRESS.md остановиться до утверждения N4A. N5 — отдельное разрешение на фактический public deploy. На N4 git push, deploy, billing/card и платные сервисы запрещены. Исторические отчёты и AGENTS в docs/history не являются текущим scope.

Актуальное решение владельца после публикации GitHub: Python-код, Python-бэкенд и инструменты Python удалены из текущего проекта. Не возвращать их; независимый исходный архив D:\Projects\NASA не изменять. Исторические отчёты о Python-проверках описывают прошлые этапы. Разрешено отправить это удаление обычным push origin main без дополнительных веток и переписывания истории.

P0 (текущая задача владельца): публичный анализ NASA POWER разрешён без Earthdata токенов. На Vercel используется отдельный power-адаптер независимо от старого EARTH_MODE=blocked/local. NASA POWER — отдельный продукт/точность; не выдавать его за прямые канонические JSON MERRA-2. Источник/единицы/происхождение должны быть явными. Старый Earthdata-адаптер и ядро OLS/HAC не удалять/не изменять. Обычный commit/push origin main и проверка автоматического Vercel deployment разрешены; 0 KZT, без новых проектов/веток/переменных/платных услуг.
