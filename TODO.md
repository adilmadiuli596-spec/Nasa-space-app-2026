# Состояние EarthMap

## Реализовано

- [x] Нативные 3D Globe и 2D Mercator, переключение проекции на одном MapLibre Map.
- [x] Сферический космический фон: локальная панорама Млечного Пути, точечные звёзды, синхронизация с камерой, обработка потери контекста, reduced motion, отсутствие постоянного цикла кадров.
- [x] Независимый выбор «Спутник / Карта», меню «Тип» с миниатюрами и клавиатурным управлением.
- [x] Все четыре сочетания проекции и подложки; переключатели видны до загрузки тайлов.
- [x] Выбор точки, дополнительные маркеры, информационная карточка.
- [x] Область двумя кликами/касаниями, предпросмотр, Esc, сброс, антимеридиан.
- [x] Локальный каталог мест и подключаемый адаптер поиска с отменой запросов.
- [x] Настраиваемые raster, GeoJSON, polygon, points и heatmap overlays; прозрачность, статусы, лимит слоёв.
- [x] Дата из props, отмена устаревших загрузок, метаданные доступности, конфигуратор NASA GIBS.
- [x] Управляемые props, callbacks, экспорт типов, ref API камеры, SSR и очистка ресурсов.
- [x] README.md и INTEGRATION.md с форматами данных и примерами.

## Фактически выполненные проверки

- TypeScript: `npm run typecheck` — успешно.
- ESLint: `npm run lint` — успешно.
- Vitest: 35 тестов в 7 файлах — успешно. Геометрия, антимеридиан, жизненный цикл, загрузка/удаление слоёв, отмена запросов, все четыре сочетания подложки и проекции, сохранение источников выбора и overlays. Дополнительно: ортонормальность небесной камеры, антимеридиан и полный оборот, ограничение разрешения, объединение событий движения, отсутствие кадров в покое, потеря/восстановление контекста, reduced motion и очистка ресурсов.
- `npm run build` — production-сборка успешно.
- `npm run verify:integration` — успешно. Отдельный Next.js host собирается с копией только earth-map и новым управляемым API подложки.
- React/MapLibre lifecycle проверяется с mock Map. Эти тесты не подтверждают реальную WebGL-отрисовку.
- Реальные WebGL shader compilation, отрисовка небесной сферы и частота кадров в браузере не проверены: браузерный коннектор недоступен. Ручная WebGL-проверка, реальные касания и визуальная проверка мобильного/настольного вида не выполнены.

## Исправления отзывчивости

- Управление доступно после style.load, а не после завершения сетевых запросов тайлов. Индикатор загрузки подложки отделён от готовности карты.
- Изменения проекции и подложки обрабатываются независимыми эффектами, без повторных одинаковых операций.
- Космос не пересоздаёт шейдеры при каждом 2D/3D. Встроенный просмотр VS Code/iframe использует движущуюся панораму без дополнительного WebGL-контекста; DPR карты ограничен 1, сглаживание MSAA отключено.
- Проверка серверов EOX, OSM и MapLibre metadata: HTTP 200, приблизительно 0,45–0,60 с с этой машины на момент проверки. Это не измерение скорости загрузки всех тайлов в VS Code.

## Текущая демо-страница

Убраны шапка, декоративный заголовок, поиск, панель научных слоёв, начальная подсказка и подключение демонстрационных слоёв с легендой. Глобус центрируется по всей ширине. Переключатели проекции/подложки, навигация, выбор и дата сохранены. API поиска и overlays остаётся доступным для основного приложения.

## Осталось и ограничения

- [ ] Выполнить визуальную проверку в браузере: четыре сочетания режимов, сеть/CORS, поиск, выбор области, resize, touch.
- [ ] Основное приложение должно подключить реальные научные продукты и подтверждённые даты через activeLayers. По умолчанию используются явно помеченные демо-геометрии.
- [ ] Для глобального поиска подключить внешний GeocodingAdapter. Встроенный каталог содержит 12 мест.
- Космос является художественным фоном, а не каталогом реальных небесных координат. Для его GPU-отрисовки используется отдельный WebGL2-контекст; при его недоступности остаётся CSS-панорама. Финальный арт и промпт находятся в assets/README.md.
- Подложки и шрифты требуют интернет. Офлайн-кеширование/скачивание не реализованы.
- EOX Sentinel-2 cloudless — историческая мозаика 2020 года, не снимок на выбранную дату. Продукты NASA GIBS — отдельные overlays.
- Стандартный OSM-сервис ограничен своей политикой использования и не предоставляет SLA. Для большой публичной нагрузки настройте собственного поставщика через baseStyle.
- При пользовательском baseStyle встроенный выбор «Спутник / Карта» скрыт; пользовательский стиль читается при монтировании.
- Выбор области использует кратчайший интервал долгот: ширина не более 180°.
- Globe адаптивно переходит к локальному Mercator при большом приближении — штатное поведение MapLibre.
